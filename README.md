Vice Meridian is a top-down open-world crime game that runs in a desktop browser from its own files: a generated city of roads, blocks, parks and waterfront, traffic and pedestrians, cars you can steal and drive with a drift model, a five-star wanted level with police who chase and arrest, three chained missions, a HUD with a live minimap, a day-night cycle with lit windows, synthesised sound and a save file. No framework, no network request, no build step.

## Run it

node serve.ts
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
